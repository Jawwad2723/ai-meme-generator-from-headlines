# AI Meme Generator from News Headlines

Generate hilarious memes from current news headlines using GPT-4 and Imgflip API.

## Features

- Automated news headline scraping
- AI-powered meme text generation
- Imgflip integration for meme creation
- Optional social media posting (Twitter/Reddit)
